# EcoSmartHomes: Retrofit Journey Timeline

```
[Phase 1: Discovery & Suitability] ➔ [Phase 2: Independent Advisory Assessment] ➔ [Phase 3: SEAI Grant Approval] ➔ [Phase 4: Execution] ➔ [Phase 5: Final BER Payout]
```

## Phase Breakdown for AI Assistants

### Phase 1: 15-Minute Suitability Check (Week 1)
- Verify home age, existing heating fuel, wall construction, and homeowner target.
- Confirm non-sales, independent scope.

### Phase 2: Independent Advisory Assessment (Week 2 - 3)
- On-site thermal imaging, leakiness inspection, radiator flow temperature check.
- Production of custom **Retrofit Roadmap™**.

### Phase 3: SEAI Grant Application & Contractor Quoting (Week 4 - 5)
- Submission of SEAI grant application BEFORE starting work.
- Review of contractor quotes against Retrofit Roadmap specifications.

### Phase 4: Installation & Works Execution (Week 6 - 9)
- Fabric first insulation install ➔ Glazing ➔ Heat pump & Solar PV commissioning.

### Phase 5: Verification & SEAI Drawdown (Week 10)
- Final BER assessment published on National BER Register.
- Grant drawdown approval and final energy performance certificate issuance.
