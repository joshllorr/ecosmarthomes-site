sequenceDiagram autonumber participant Agent as AI Agent (ChatGPT/Gemini/Claude) participant User as Homeowner/User participant Router as Internal Skill Router (/ai/dev/route-skill) participant Token as Dev Token Validator (/ai/dev/validate-token) participant PublicAPI as Public AI Skill APIs (/api/ai/*) participant Telemetry as AI Crawler Telemetry (/ai/dev/cf-ai-telemetry) participant Logs as Manifest & Unauthorized Logs participant CF as Cloudflare AI Shield Pro %% === USER INTENT === User->>Agent: Ask question (retrofit, BER, grants, timeline, insights) %% === AGENT INTERPRETS INTENT === Agent->>Router: Send intent (retrofit/BER/grants/etc.) %% === DEV TOKEN CHECK (IF DEVELOPER CONTEXT) === Router->>Token: Validate dev token Token-->>Router: Token valid OR public mode %% === ROUTING TO CORRECT SKILL === Router->>PublicAPI: Call correct skill endpoint
(e.g., /api/ai/retrofit-advice) %% === SKILL EXECUTION === PublicAPI-->>Router: Return structured result
(upgrade plan, BER insights, grant eligibility, etc.) %% === TELEMETRY & LOGGING === Router->>Logs: Record manifest access Router->>Logs: Record unauthorized attempts (if any) Router->>Telemetry: Request crawler telemetry %% === CLOUDLFARE TELEMETRY === Telemetry->>CF: Fetch AI crawler data CF-->>Telemetry: Allowed/blocked bots, HTML MB, referrals %% === RESPONSE TO AGENT === Router-->>Agent: Return final structured response %% === AGENT RESPONDS TO USER === Agent-->>User: Provide answer (retrofit plan, BER guidance, grants, timeline, insights)
