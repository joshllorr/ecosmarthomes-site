Token Lifecycle & Rotation Rules

Developer tokens rotate every 6–12 months. Expired or revoked tokens immediately lose access to:

  • /ai/dev/ (Private Developer Portal)
  • /ai/manifest.json (AI Plugin & Agent Manifest)
  • /api/mcp/manifest.json (Model Context Protocol Manifest)
  • /.well-known/oauth-authorization-server (RFC 8414 Metadata)
  • /api/upgrades/recommendations.md (Retrofit Advisory Specs)
