How Token Issuance Works

Tokens are generated using your Node utility script scripts/generate-dev-token.js and registered in site/data/dev-tokens.json. This UI provides a guided workflow.

Issuance Form

Generate New Token

Enter a unique Token ID and click generate to inspect CLI issuance commands and JSON registry snippets.

Registry Payload

Register Token Payload

After generating the token via CLI, add the following entry to the active array in site/data/dev-tokens.json:

{
  "id": "dev-2026-02",
  "label": "Partner Token (dev-2026-02)",
  "issued": 1785955000,
  "expires": 1817491000
}
